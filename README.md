# MinMyndighed – Det Fælles Designsystem Website

A demo website built with [Det Fælles Designsystem (DKFDS)](https://designsystem.dk/), Denmark's official design system for public self-service solutions.

## Pages

- **Forside** (`/`) – Landing page with hero section, service cards, alerts, and FAQ accordion
- **Komponenter** (`/components/`) – Showcase of DKFDS components: buttons, alerts, tags, cards, accordion, table, details, structured list, pagination, tabs, tooltip, and spinner
- **Kontakt** (`/contact/`) – Contact form demonstrating form components: text inputs, email, phone, select dropdown, radio buttons, textarea, checkboxes, and date fields

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Tech Stack

- [DKFDS](https://www.npmjs.com/package/dkfds) v11 – Det Fælles Designsystem
- [Vite](https://vite.dev/) – Build tool and dev server
